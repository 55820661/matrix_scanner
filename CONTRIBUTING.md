# Contributing

Thanks for considering a contribution! Please follow these steps:

1. Fork the repository.
2. Create a topic branch (git checkout -b feature/your-change).
3. Run tests and linters locally.
4. Open a pull request with a clear description and related issue (if any).
5. Keep changes focused and documented.

Small PRs are easier to review. If your change is large, open an issue first to discuss the approach.
